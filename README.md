# FINEXO Expense Tracker

A personal Expense Tracker project developed as an academic mini-project during the second year of engineering. The application is designed to help users record, categorize, manage, and analyze their daily expenses.

## 📌 Project Overview

The **FINEXO Expense Tracker** is designed to help users maintain an organized record of their financial transactions. It provides features for managing expenses, categorizing spending, and generating reports to help users understand their spending habits.

This project was originally developed as a **second-year academic mini-project**. I am publishing this project on GitHub as part of my learning and project portfolio. I did **not originally develop the complete project myself**; the project was provided to me by a friend. I am using this repository to study the project, understand its implementation, and document it as part of my academic learning.

## 🎯 Objectives

The main objectives of the project are:

* Provide a user-friendly interface for managing daily expenses.
* Allow users to categorize their expenses.
* Store financial records in a structured manner.
* Help users analyze their spending patterns.
* Generate financial reports to provide insights into spending habits.
* Help users make better financial and budgeting decisions.

## ✨ Features

### 1. User-Friendly Interface

* Simple navigation.
* Easy access to different sections of the application.
* Dashboard-based access to commonly used functions.

### 2. Expense Management

Users can:

* Add expenses.
* Edit existing expenses.
* Delete expenses.
* Specify expense amount.
* Specify expense date.
* Select an expense category.
* Add an expense description.

### 3. Expense Categorization

Expenses can be grouped into categories to make spending easier to track and analyze.

### 4. Recurring Expenses

The project includes support for recurring expenses such as monthly bills, which can be automatically added to the expense list.

### 5. Reports

The application provides financial reports that help users understand their spending habits and identify areas for financial improvement.
